# Web server

Configuring an Nginx web server on Ubuntu with Bash scripts.

| File | Description |
| --- | --- |
| `0-transfer_file` | Transfers a file to a server's home directory with scp |
| `1-install_nginx_web_server` | Installs Nginx on port 80, serving a page containing Holberton School |
| `2-setup_a_domain_name` | Domain name pointing to web-01 |
| `3-redirection` | /redirect_me returns 301 Moved Permanently |
| `4-not_found_page_404` | Custom 404 page containing Ceci n'est pas une page |
| `5-design_a_beautiful_404_page.html` | Designed 404 page |
